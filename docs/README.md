# CakePHP Data documentation

Read the [documentation website](https://dereuromark.github.io/cakephp-data/), starting with [Installation](https://dereuromark.github.io/cakephp-data/guide/installation) and [Getting started](https://dereuromark.github.io/cakephp-data/guide/getting-started).

To work on the website locally, run `npm ci` in this directory, then `npm run docs:dev`. Run `npm run docs:build` before submitting documentation changes.
